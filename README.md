# 🏋️ Gym Management System

## About The Project

Gym Management System is a web-based application developed to simplify gym operations and membership management. It helps gym owners manage members, track attendance, monitor membership expiry and maintain gym records efficiently.

## Features

- Admin Login and Logout
- Member Registration
- Add, Update and Delete Members
- Member Dashboard
- Attendance Management
- Membership Expiry Tracking
- Member Cards
- Password Management
- Responsive User Interface

## Technologies Used

- Java
- Spring Boot
- Thymeleaf
- HTML
- CSS
- JavaScript
- Maven
- MySQL (if configured)

## Project Structure

- `src/main/java` – Java backend
- `src/main/resources/templates` – HTML templates
- `src/main/resources/static/css` – CSS files
- `src/main/resources/static/js` – JavaScript files
- `src/main/resources/static/images` – Images

## How to Run

1. Clone the repository.
2. Open the project in VS Code or IntelliJ IDEA.
3. Configure the database connection.
4. Run the Spring Boot application.
5. Open your browser and visit:

`http://localhost:8080`
