# FitZone Gym Management System

Live demo: https://gym-management-system-5v42.onrender.com

## Features
- Owner and Member login
- Add / renew members with plan and expiry
- QR member card with verify page
- Payments and attendance tracking
- Notifications for expiring memberships

## Tech stack
Java, Spring Boot, Spring Security, Thymeleaf, JPA/Hibernate, H2
